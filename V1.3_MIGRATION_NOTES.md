# CropLab v1.3 — Editor Workspace

## Scope

v1.3 redesigns the editing environment around a three-zone workspace:

- **Edit** — persistent primary tool navigation for Crop, Resize, Compress, and Adjust.
- **Canvas** — focused image workspace with a persistent transform toolbar.
- **Export** — always-visible output controls and download action.

## Persistent controls

Undo, redo, rotate left/right, horizontal/vertical flip, zoom, replace, clear, and reset remain available without opening a secondary menu.

## Primary tools

- Crop exposes aspect-ratio controls.
- Resize points to exact output dimensions in Export.
- Compress points to format/quality controls in Export.
- Adjust is intentionally presented as a reserved workspace section; image-adjustment controls are not faked or partially implemented in v1.3.

## Preserved behavior

- react-easy-crop interaction and cropper transform behavior
- repeated flip stability fix from v1.1
- undo/redo history
- local-only image processing
- PNG/JPEG/WebP export
- custom output dimensions and aspect-ratio lock
- theme persistence
- upload, drag/drop, and clipboard paste
