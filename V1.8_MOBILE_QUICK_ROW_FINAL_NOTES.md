# CropLab v1.8 — Mobile Quick Row Final

## Scope

Final mobile quick-control refinement only. No changes to the editing engine, crop engine, export engine, history engine, image loading, validation, or desktop layout.

## Changes

The persistent upper mobile quick row is now:

- Undo
- Redo
- divider
- Rotate left 90°
- Rotate right 90°
- divider
- Flip H
- Flip V
- divider
- Zoom in
- Zoom out
- 100%

The previous bottom navigation buttons for Rotate and Flip are removed. The bottom mobile navigation is now:

- Crop
- More
- Export

Rotate and flip controls remain available inside More as secondary access points.

The existing 44px-class mobile interaction targets and accessibility labels are preserved.
