# CropLab v1.8 — Mobile + Accessibility

## Scope

v1.8 is limited to mobile interaction design and accessibility improvements. The existing desktop editing, history, image-loading, and export behavior is preserved.

## Mobile interaction model

- Replaces the desktop three-column interaction model below 900px with a dedicated mobile canvas workspace.
- Hides the desktop editing sidebar and persistent toolbar on mobile.
- Adds a bottom mobile action bar for Crop, Rotate, Flip, More, and Export.
- Adds focused mobile control sheets instead of compressing the desktop controls into a smaller layout.
- Keeps Export as a full-height scrollable mobile panel when opened.
- Keeps high-value actions directly reachable and moves lower-frequency actions under More.
- Preserves touch zoom/crop interaction and adds explicit tap alternatives for transforms and zoom.

## Accessibility

- Adds a keyboard-accessible skip link.
- Adds stronger `:focus-visible` treatment and touch-friendly mobile targets.
- Adds `aria-live`/atomic toast announcements.
- Improves history dialog labelling and adds keyboard focus containment.
- Preserves descriptive labels on icon-only controls and adds mobile pressed states.
- Adds a reduced-motion media-query variant.
- Keeps browser zoom enabled and increases mobile form control text size to avoid iOS focus zoom/layout surprises.
- Uses native controls and semantic navigation wherever possible.

## Desktop safety

No desktop layout redesign is included. Desktop components and editing/export logic remain intact; v1.8 adds responsive behavior and accessibility layers around them.
