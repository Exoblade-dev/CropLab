# CropLab v1.2

## Focus

v1.2 is the first editor UX pass after the v1.1 foundation freeze.

### Included

- Neutral, minimal editor visual system.
- Checkerboard transparency-style canvas background.
- Clearer editor hierarchy and export hierarchy.
- Editor toolbar extracted into `EditorToolbar`.
- Editor controls extracted into `EditorSidebar`.
- Export workflow extracted into `ExportPanel`.
- Improved upload screen semantics and keyboard interaction.
- Removed the emoji-based privacy indicator from the UI.
- Theme state migrated away from synchronous state updates inside an effect.
- Editor history capped at 50 snapshots to avoid unbounded memory growth.
- Zoom and rotation controls use pointer interaction for history checkpoints.
- Existing flip transform fix from v1.1 remains intact.
- Existing functionality and export formats remain unchanged.

## Important

This is an overlay patch, not a replacement repository.

Extract the ZIP directly into the existing CropLab repository and overwrite matching files.

After extraction:

1. Delete the tracked `tsconfig.tsbuildinfo` file from the repository. It is a generated TypeScript artifact and should not be committed.
2. Add `*.tsbuildinfo` to `.gitignore` if it is not already ignored.
3. Run the full local verification suite.

## Verification

Run:

- `npm.cmd run typecheck`
- `npm.cmd run lint`
- `npm.cmd run test`
- `npm.cmd run build`
- `npm.cmd run start`

Then manually test:

- upload, drag/drop, and paste
- crop dragging
- zoom
- rotation
- horizontal and vertical flip
- repeated mixed transforms
- undo/redo
- aspect ratio changes
- output dimensions
- PNG/JPEG/WebP export
- light/dark theme persistence
- mobile layout
- keyboard accessibility

## Freeze criteria

v1.2 should be frozen only after all four automated checks pass and the manual regression pass shows no functional regressions.
