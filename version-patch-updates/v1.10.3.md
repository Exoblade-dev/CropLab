# v1.10.3 — Preview comparison and output inspection

## Preview comparison

- Added `After` / `Before` controls inside the Preview toolbar.
- `Before` renders the same crop, transform, resize, format, quality, and JPEG background with adjustments reset to their neutral values.
- The Preview canvas remains dedicated to hand-pan and wheel/trackpad zoom; comparison is controlled from the toolbar.
- The Before preview uses the same interactive resolution ceiling as the normal preview.
- At 200% and 400%, Before can request its own full-resolution inspection render.

## Output information

The Preview details panel now shows:

- output dimensions
- source dimensions
- format
- quality
- exact export size when a full-resolution inspection has been prepared
- estimated preview size before exact inspection
- size change versus the original source file
- transparency behavior

## Scope

No changes to crop geometry, editor history, adjustment algorithms, export geometry, or the Phase 3 interactive adjustment performance boundary.
