# CropLab v1.3 — Editor Workspace

## Scope
Redesigned the editor around three zones:

- **Edit** — Crop, Resize, Compress, Adjust.
- **Canvas** — focused image workspace with persistent transforms.
- **Export** — always-visible output controls and download.

## Persistent controls
Undo, redo, rotate left/right, horizontal/vertical flip, zoom, replace, clear, and reset.

## Primary tools
- Crop exposes aspect-ratio controls.
- Resize points to exact output dimensions.
- Compress points to format/quality controls.
- Adjust remains a reserved section; unfinished adjustment controls were not faked.

## Preserved
react-easy-crop behavior, flip stability, undo/redo, local-only processing, PNG/JPEG/WebP export, dimensions/aspect lock, theme persistence, upload, drag/drop, and clipboard paste.

## Verification
TypeScript/JSX validity was checked, followed by repository typecheck, lint, tests, build, startup, and browser QA.

## Freeze
v1.3 established the three-zone editor workspace.
