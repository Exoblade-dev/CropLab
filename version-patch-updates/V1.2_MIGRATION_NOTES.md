# CropLab v1.2 Migration Notes

## Scope

v1.2 focused on stabilizing the editor foundation and clarifying the editing workspace without changing the core image-editing model.

## Changes

- Introduced a more neutral/minimal editor presentation.
- Added a checkerboard canvas background for transparent-image context.
- Separated editor, toolbar, upload, and export UI into reusable components.
- Added a bounded editor history implementation.
- Hardened theme state for Next.js server rendering and hydration.
- Improved upload/replace/clear semantics.
- Preserved the existing crop, resize, transform, history, export, upload, and theme workflows.

## Verification

The v1.2 implementation was verified with typecheck, lint, tests, production build, and local browser startup.

## Freeze

v1.2 was frozen before the v1.3 workspace redesign.
