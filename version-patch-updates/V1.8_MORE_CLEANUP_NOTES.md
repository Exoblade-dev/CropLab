# CropLab v1.8 — More Menu Cleanup

Removed the redundant editing controls from the mobile More sheet:

- Zoom out
- Fit
- 100%
- 200%
- Zoom in
- Flip H
- Flip V
- Rotate left
- Rotate right

These controls are already available in the persistent upper quick row.

The More sheet now contains only secondary actions:

- Undo
- Redo
- History
- Replace
- Clear
- Reset

No editor engine, crop interaction, export, history implementation, or desktop layout changes were made.
