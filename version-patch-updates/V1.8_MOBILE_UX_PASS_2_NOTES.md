# CropLab v1.8 — Mobile UX Pass 2

## Scope

This patch refines the mobile interaction model only. It does not change the editing engine, export engine, history engine, image loading, validation, or desktop layout.

## Changes

- Give the mobile canvas the full free workspace area between the header and bottom controls.
- Remove the artificial short canvas height that made wide images difficult to inspect and edit.
- Replace the mobile quick-action row with the requested sequence:
  - Undo
  - Redo
  - Rotate left 90°
  - Rotate right 90°
  - Zoom out
  - 100%
  - Zoom in
- Remove Fit and the live zoom percentage from the persistent quick row.
- Keep lower-frequency controls in More.
- Convert mobile Export into a centered modal-style popup with a backdrop and internal scrolling.
- Add a dedicated Close button and backdrop dismissal for the mobile Export popup.
- Keep the existing bottom navigation: Crop, Rotate, Flip, More, Export.
- Preserve touch-target and accessibility behavior.

## Desktop

No desktop layout or desktop export behavior is changed by this patch.
