# CropLab v1.8 — Mobile + Accessibility

## Scope
Introduced a dedicated mobile interaction model and accessibility layer while preserving the desktop editor, history, image-loading, and export behavior.

## Mobile interaction
- Replaced the desktop three-column interaction model below the mobile breakpoint with a dedicated mobile canvas workspace.
- Hid desktop editing sidebar and persistent toolbar on mobile.
- Gave the mobile canvas the available free workspace area instead of an artificial fixed height.
- Kept high-frequency actions directly reachable.
- Used focused mobile control surfaces instead of shrinking desktop UI into a phone layout.
- Preserved touch crop dragging, zoom, and pinch interaction.

## Final mobile quick row
```text
Undo  Redo | Rotate left  Rotate right | Flip H  Flip V | Zoom in  Zoom out  100%
```

Fit and the live zoom percentage were removed from the persistent row.

## Final mobile navigation
```text
Crop | More | Export
```

Rotate and Flip were removed from bottom navigation because they are already available in the persistent quick row.

## Final More menu
Only secondary actions remain:
- Undo
- Redo
- History
- Replace
- Clear
- Reset

Redundant zoom, rotation, and flip controls were removed.

## Mobile Export
- Centered modal-style popup with backdrop.
- Dedicated close control.
- Internal scrolling when needed.
- Existing export engine and desktop export behavior unchanged.

## Crop interaction fix
The mobile cropper interaction surface was made explicit instead of relying solely on react-easy-crop injected positioning while responsive dimensions changed.

- Cropper container explicitly fills the canvas stage.
- Pointer hit-testing explicitly enabled.
- `touch-action: none` preserved for drag/pinch.
- Grab/grabbing cursor feedback added.
- Mobile workspace grid explicitly set to `width: 100%`.
- No editor-state, crop-engine, export-engine, history-engine, or image-loading changes.

## Accessibility
- Keyboard-accessible skip link.
- Stronger `:focus-visible`.
- Touch-friendly mobile targets.
- `aria-live` / atomic toast announcements.
- Improved History dialog labelling, focus containment, and focus restoration.
- Descriptive icon-only control labels.
- Mobile pressed states.
- Reduced-motion support.
- Browser zoom preserved.
- Mobile form controls use appropriate text sizing for iOS.
- Native controls and semantic navigation preferred.

## Intermediate repairs incorporated into final v1.8
- Restored the base application stylesheet after an intermediate mobile patch accidentally replaced it.
- Refined mobile canvas sizing and workspace usage.
- Hardened Cropper interaction.
- Finalized the quick-row grouping and controls.
- Simplified the More menu.
- Converted mobile Export into a popup.

## Verification
Typecheck, lint, tests, production build, local startup, desktop browser QA, and physical-phone mobile QA were completed during the final v1.8 stabilization cycle.

The final v1.8 deployment was successfully verified on Vercel.
