# CropLab v1.1 — Foundation & Architecture

## Scope
Established the maintainable browser-based image-editor foundation.

## Changes
- Migrated the original Vite application toward the Next.js application structure.
- Introduced dedicated component, hook, library, and type layers.
- Separated image, edit, view, export, and application concerns.
- Extracted image loading, validation, transformations, export calculations, history, keyboard handling, and theme handling.
- Preserved upload, drag/drop, clipboard paste, replace, clear, crop, zoom, rotation, flip, aspect ratios, undo/redo, dimensions, aspect locking, PNG/JPEG/WebP export, theme persistence, toast feedback, and 50 MB validation.

## Flip stability
- Restored the complete cropper transform when flipping.
- Preserved crop position, rotation, and zoom.
- Added transform regression coverage.

## Verification
Typecheck, lint, tests, production build, and browser QA were used during stabilization.

## Freeze
v1.1 established the baseline for subsequent releases.
