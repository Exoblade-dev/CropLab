# CropLab v1.7 Export UI Polish

This patch refines the existing v1.7 export engine and history-compatible export workspace without changing the export pipeline.

## Changes

- Reworked the right-side Export workspace into a structured, format-aware layout.
- Kept the export column independent from the History modal so the full workspace remains available.
- Replaced the cramped JPEG quality labels with three proper Low / Medium / Best preset controls.
- Kept the continuous quality slider at 20%–100% and made the current value explicit.
- Added format capability summaries for PNG, JPEG, and WebP using the existing format registry.
- Added explicit transparency messaging for PNG/WebP.
- Redesigned JPEG background handling into White / Black / Custom presets with a color value preview.
- Reworked output dimensions into a dedicated section with the existing locked/free aspect behavior.
- Reworked output statistics into a compact six-cell summary.
- Moved export status and download into a stable footer so the download action does not jump as format-specific controls change.
- Preserved browser capability detection: unsupported canvas encoders remain unavailable.
- Preserved the existing export engine, real encoded-size estimation, JPEG compositing behavior, and download flow.
- Added responsive behavior so the structured export layout remains usable on smaller screens.

## Scope

This is an Export UI/architecture polish pass for v1.7. It does not add new binary encoders such as TIFF, GIF animation, or JPEG XL. Those should be introduced only when a deliberate browser/client-side encoder exists and can be represented honestly by the format registry.

## Verification

Run from the updated CropLab repository:

```powershell
npm.cmd install --package-lock-only
npm.cmd run typecheck
npm.cmd run lint

```

Browser QA should cover:

1. PNG layout and transparent export.
2. JPEG layout, quality presets, slider, and White / Black / Custom background.
3. WebP quality and transparency messaging.
4. Switching formats repeatedly without layout glitches.
5. Width/height locking and free dimensions.
6. Estimated output size and reduction updating after format/quality/dimension changes.
7. Export status and Download button staying anchored at the bottom of the right workspace.
8. History opening beside Undo/Redo and remaining unaffected by Export layout.
9. Dark and light themes.
10. Narrow desktop/mobile widths.
