# CropLab v1.7 — History, Interaction & Export Workspace

## History
- Replaced the side history panel with a modal timeline.
- Export remains the full-height right workspace.
- Labeled editor states replace anonymous undo snapshots.
- Original state plus up to 50 edit operations retained.
- Direct history-state selection.
- Linear history: editing from an older state discards the future branch.
- Complete editor state restored, including crop/transform, crop area, output dimensions, aspect lock, format, quality, background, and crop ratio.
- Zoom/navigation excluded from history.

## Keyboard
- Ctrl/Cmd+Z — Undo.
- Ctrl/Cmd+Shift+Z — Redo.
- R — Rotate 90° right.
- 0 — Fit.
- 1 — 100%.
- 2 — 200%.
- +/= — Zoom in.
- - — Zoom out.
- Esc — Exit active section.
- Ctrl/Cmd+O — Open image through replacement flow.
- Ctrl/Cmd+S — Export.
- Shortcuts centralized and ignored while interacting with form controls.

## Export UI
- Structured format-aware PNG/JPEG/WebP workspace.
- Low/Medium/Best presets plus 20%–100% slider.
- Format capability summaries.
- PNG/WebP transparency messaging.
- JPEG White/Black/Custom backgrounds.
- Dedicated output dimensions.
- Compact statistics.
- Stable status/download footer.
- Browser capability detection preserved.
- Existing export engine and encoded-size calculation preserved.
