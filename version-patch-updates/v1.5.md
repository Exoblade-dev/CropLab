# CropLab v1.5 — Export Engine & Release Cleanup

## Export engine
- Format registry for PNG, JPEG, and WebP.
- Browser capability detection for supported encoders.
- Format metadata for MIME, extension, quality, transparency, and background support.
- JPEG/WebP quality from 20%–100%.
- Explicitly explains that quality is not a file-size percentage.
- Actual encoded Blob size used for output-size estimates.
- Original size, estimated output size, and reduction shown.
- JPEG transparency handled through background color.
- Format-independent output dimensions.
- Preparing, Cropping, Resizing, Encoding, Downloading, Complete states.
- Debounced export preview.
- Extensible registry architecture.
- Existing editing, history, upload, and local-only behavior preserved.

## Technical basis
Canvas `toBlob()` provides client-side encoding. PNG is required; JPEG/WebP are offered only when the browser reports encoder support.
