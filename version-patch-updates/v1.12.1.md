# v1.12.1 — Batch Rail & Export UX

## Changes

- Hid vertical and horizontal thumbnail-list scrollbars while preserving scrolling.
- Increased the desktop image collection rail width slightly for better thumbnail controls.
- Added a top-right remove control to every collection thumbnail.
- Collection removal uses the existing destructive confirmation flow and preserves per-image history for remaining images.
- Expanded the Export drawer footer to expose two explicit actions:
  - Export current image
  - Export full batch as ZIP
- Batch export progress/cancellation is also available from the Export drawer.
- Kept the existing single-image export pipeline and Phase 6 batch pipeline unchanged.

## Verification target

Run `npm run typecheck`, `npm run lint`, `npm run test`, `npm run build`, then verify the rail and export drawer manually on desktop and mobile.
