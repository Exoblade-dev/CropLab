# v1.10.2 — Preview inspection and format controls

## Preview inspection

- Keeps `Fit` as the initial preview state.
- Uses the existing interactive preview for responsive Fit/50%/100% inspection.
- Generates the exact export dimensions on demand when the user reaches 200% or 400% zoom, avoiding thumbnail upscaling blur.
- Keeps the high-resolution inspection render out of the normal editing path so large-image adjustment responsiveness is preserved.
- Shows a loading state while the full-resolution inspection render is being prepared.
- Reports the exact export blob size after the full-resolution inspection render completes.

## Preview format controls

- Adds PNG, JPEG, and WebP controls directly inside the Preview window.
- Format changes update the editor's actual export format and therefore regenerate the preview.
- The Preview dialog remains open while the new format preview is preparing.

## Preview layout

- The main preview viewport now fills the modal's available height.
- JPEG's transparency note is kept inside the details card so it no longer creates an unnecessary second grid row and large empty area.

## Scope

No changes to crop geometry, editor history, adjustment algorithms, export geometry, or the Phase 3 interactive adjustment performance cap.
