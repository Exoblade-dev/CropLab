# CropLab v1.10 — Interactive Export Preview

## Scope

The export preview is now an interactive inspection viewport rather than a static image modal.

## Preview viewport

- Opens in `Fit` mode by default.
- Fits the complete exported preview inside the viewport while preserving its aspect ratio.
- Supports fixed zoom presets:
  - Fit
  - 50%
  - 100%
  - 200%
  - 400%
- Provides zoom out/in buttons.
- Supports mouse wheel and trackpad scrolling for zooming.
- Wheel zoom is anchored around the pointer position so the inspected area stays under the cursor when changing zoom.
- Supports click/touch drag panning when the image is zoomed.
- The preview canvas uses a grab/grabbing hand cursor and disables native image dragging/selection.
- Panning is bounded so the viewport cannot expose arbitrary empty space around the image.
- Preview viewport state is local UI state and does not enter editor history.

## Preview information

The existing output information remains available beside the viewport:

- Dimensions
- Format
- Quality
- Estimated size
- JPEG background compositing note

## Performance boundary

The existing interactive preview resolution ceiling remains unchanged. The preview viewport inspects the generated preview Blob, while the real export path continues to use the requested output dimensions.

## Verification target

After extraction:

```powershell
npm.cmd install
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run test
npm.cmd run build
npm.cmd run start
```

Manual validation should confirm:

1. Preview opens at `Fit` and shows the entire exported image.
2. 50/100/200/400% presets show the expected scale.
3. `+` and `-` step through the supported zoom levels.
4. Wheel/trackpad zoom works without scrolling the page behind the modal.
5. Dragging pans the image only when zoomed.
6. Panning cannot move the image beyond its viewport bounds.
7. Closing and reopening Preview resets to `Fit`.
8. The output dimensions shown in the details panel remain the actual requested export dimensions, not the capped interactive preview dimensions.
