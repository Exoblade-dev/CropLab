# v1.12.2 — Remove Replace Image Controls

## Change

Removed the visible **Replace image** controls from the desktop editor toolbar and mobile More controls.

The underlying replace flow remains available to preserve the existing `Ctrl/Cmd + O` open/replace shortcut behavior and collection compatibility.

## Scope

- Desktop Replace button removed.
- Mobile Replace button removed.
- Replace input and keyboard shortcut flow retained.
- No changes to image collection, deletion, export, or batch behavior.
