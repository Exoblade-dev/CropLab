# CropLab v1.4 — Editing Engine & UX

## Scope

v1.4 improves the interaction model of the existing editor without expanding the product into a new feature set.

### Crop
- Free crop remains available.
- Aspect-ratio presets now have visual ratio representations.
- Crop dimensions are shown in pixels.
- Crop reset restores the crop position and zoom without removing rotation/flip state.
- Cropper interactions participate in editor history.

### Resize
- Width and height are explicit pixel properties.
- Maintain-aspect-ratio is enabled by default.
- Changing width immediately derives height from the current crop ratio.
- Changing height immediately derives width from the current crop ratio.
- Unlocking the ratio allows independent dimensions.

### Rotation
- Persistent 90° left/right controls remain available.
- Rotation now has a -180° to 180° slider.
- Rotation interactions participate in editor history.

### Flip
- Existing icon-first horizontal/vertical controls are preserved.
- The v1.1 full-transform flip regression fix is preserved.

### Zoom
- Zoom range is now 20%–200%.
- Persistent minus/plus controls are available.
- Fit, 100%, 200%, and Reset presets are available.
- Mouse-wheel zoom remains enabled through react-easy-crop.
- Touch pinch remains supported by react-easy-crop.
- Keyboard shortcuts: `+` / `=` zoom in, `-` zoom out, `0` reset to 100%, `1` = 100%, `2` = 200%.
- Cropper arrow-key movement remains available through its keyboard navigation.
