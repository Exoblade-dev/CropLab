# CropLab v1.7 — History & Interaction System

## Scope

- Replace the compact side history panel with a modal history workspace opened from the persistent toolbar.
- Keep the export panel as the full-height right-side workspace; history no longer competes with export space.
- Track labeled editor states rather than anonymous undo snapshots.
- Preserve up to 50 edit operations plus the original state.
- Allow direct selection of any retained history state.
- Follow Photoshop-style linear history behavior: selecting an older state and making a new edit discards the future branch.
- Restore the complete editor state represented by a history entry, including crop/transform state, crop area, output dimensions, aspect lock, format, quality, background, and crop ratio.
- Keep zoom/navigation out of history because it is a view operation rather than an image edit.

## History UI

- History button sits beside Undo and Redo in the persistent toolbar.
- Clicking History opens a modal timeline.
- The original state is always available at the top.
- The current state is highlighted.
- Future states are visually dimmed when the user has stepped backward.
- Clicking any state immediately restores that editor state.
- Selecting an older state and then editing creates a new branch and removes the future states, matching Photoshop's default linear-history behavior.
- The modal closes with its close button, backdrop, or Escape.

## Keyboard shortcuts

- Ctrl/Cmd + Z — Undo
- Ctrl/Cmd + Shift + Z — Redo
- R — Rotate 90° right
- 0 — Fit
- 1 — 100%
- 2 — 200%
- + / = — Zoom in
- - — Zoom out
- Esc — Exit the active editing section
- Ctrl/Cmd + O — Open image through the same replacement confirmation flow as the toolbar
- Ctrl/Cmd + S — Export image

Shortcuts remain centralized and are ignored while the user is interacting with form controls.

## Export workspace

- Removed the history panel from the export column.
- Export now occupies the complete right-side workspace height.
- Desktop export layout is compacted so the format, quality, background, dimensions, statistics, status, and download controls remain visible together when the viewport permits.
- Smaller screens retain scrolling where necessary.

## Verification

Run after applying the patch:

```powershell
npm.cmd install --package-lock-only
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run test
npm.cmd run build
npm.cmd run start
```

Then browser-test:

1. Open and close History.
2. Perform Crop → Rotate → Flip → Resize and verify every state appears in order.
3. Click an older history state and verify the editor returns to that exact state.
4. Make a new edit from an older state and verify future history entries disappear.
5. Undo and redo after history jumps.
6. Verify zoom changes do not create history entries.
7. Verify Ctrl/Cmd+O uses the replacement confirmation flow.
8. Verify Ctrl/Cmd+S exports without affecting history.
9. Verify typing, sliders, selects, and buttons do not trigger unrelated keyboard shortcuts.
10. Verify the export panel remains full-height and its controls are not displaced by history.
