# CropLab v1.7 — History & Interaction System

## Scope

- Replace state-only undo/redo storage with labeled editor operation history.
- Keep history capped at 50 operations.
- Track crop, rotation, flips, zoom, resize, output format, and compression quality changes.
- Add a compact history panel beside the export panel.
- Add centralized keyboard shortcuts for undo/redo, rotate, zoom, open, export, and escape.
- Ignore shortcuts while typing in inputs, textareas, selects, buttons, or content-editable elements.
- Keep shortcut handling in the interaction hook instead of scattering window key handlers through the UI.

## History model

Each history entry stores a labeled editor snapshot. Snapshots contain crop/transform state plus output dimensions, format, quality, background, and selected crop ratio so undo/redo can restore the complete editing state represented by an operation.

## Keyboard shortcuts

- Ctrl/Cmd + Z — Undo
- Ctrl/Cmd + Shift + Z — Redo
- R — Rotate 90° right
- 0 — Fit
- 1 — 100%
- 2 — 200%
- + / = — Zoom in
- - — Zoom out
- Esc — Exit the active editing section
- Ctrl/Cmd + O — Open image
- Ctrl/Cmd + S — Export image

Shortcuts are ignored while the user is interacting with editable form controls.
