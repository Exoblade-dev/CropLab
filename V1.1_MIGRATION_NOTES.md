# CropLab v1.1 migration notes

## Replace / add

Copy the contents of this package into the repository root, preserving the paths.

## Delete from the existing Vite project

These are intentionally removed in v1.1:

- `vite.config.ts`
- `tsconfig.app.json`
- `tsconfig.node.json`
- `src/main.tsx` (the file is retained in the package only as a migration marker; it is no longer the application entry point)
- `src/assets/react.svg`
- `src/assets/vite.svg`
- the old `package-lock.json`
- `dist/` if it exists locally

The existing `public/` directory may be retained.

## Install after copying

Use the package manager normally used for this repository. With PowerShell on the user's machine, `npm.cmd` is expected:

```powershell
npm.cmd install
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run test
npm.cmd run build
npm.cmd run start
```

Do not move on to v1.2 until those checks pass and the manual regression checklist is complete.
