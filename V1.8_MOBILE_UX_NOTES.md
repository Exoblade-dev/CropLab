# CropLab v1.8 Mobile UX Pass

## Scope

This patch keeps the repaired v1.7 desktop foundation and refines only the mobile interaction model.

## Mobile UX changes

- Make the image canvas substantially shorter and proportional to the available mobile viewport so wide images remain large and usable.
- Keep the canvas centered as the primary workspace instead of making it occupy most of the screen with large empty checkerboard areas.
- Add a persistent quick-action row for Undo, Redo, Zoom out, Fit, 100%, Zoom in, and the current zoom percentage.
- Keep high-frequency actions directly visible in the main mobile navigation: Crop, Rotate, Flip, More, Export.
- Keep lower-frequency destructive/history actions under More.
- Preserve the existing Crop sheet and More sheet rather than replacing the editing engine.
- Preserve mobile Export as a dedicated full-height view.
- Remove the mobile canvas minimum-height behavior that made the editor feel like a desktop canvas squeezed into a phone.
- Keep touch targets at or above the existing accessibility target.

## Intentionally unchanged

- Desktop layout
- Export engine and Export UI
- Crop engine
- History engine
- Image loading/validation
- Keyboard shortcut architecture
- Theme system
